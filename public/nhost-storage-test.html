ENVIRONNEMENT FICTIF — AUCUN FICHIER DANZ RÉEL

Test Nhost Storage depuis le poste professionnel

Ce test utilise seulement un minuscule fichier texte fictif, jamais une photo ou un document de l'Amicale. Il vérifie qu'un utilisateur peut gérer ses fichiers, mais pas ceux des autres.

1. Préparer le stockage dans Nhost

Dans Nhost → Storage, crée un bucket nommé danz-test-private. Dans Storage → Permissions, configure uniquement le rôle user :

  • Upload : condition bucket_id = danz-test-private ; activer « Uploader identity » pour remplir uploaded_by_user_id.
  • Download et Delete : conditions bucket_id = danz-test-private ET uploaded_by_user_id = X-Hasura-User-Id.
  • Ne donne aucun accès aux rôles public ou anonymous. N'utilise jamais le secret administrateur dans cette page.

Aucun compte connecté.

Ton mot de passe est effacé après la tentative ; le jeton est conservé uniquement en mémoire tant que la page reste ouverte. N'entre pas ton compte DANZ réel.
