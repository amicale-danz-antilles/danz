Ce que ces résultats signifient

Réponse HTTP (même 400, 401 ou 404) : la requête a atteint le service et le navigateur a pu lire sa réponse.

« Échec réseau / CORS » : le navigateur n'a pas pu lire la réponse. Cela peut venir d'un filtrage réseau ou des règles CORS du serveur. Il faut distinguer les deux avant toute migration.

Le test GraphQL utilise une requête anonyme { __typename }. Le stockage teste volontairement un identifiant de fichier inexistant. Aucune donnée personnelle n'est envoyée et aucune écriture n'est effectuée.
