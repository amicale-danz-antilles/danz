# Amicale DANZ Antilles

Application web privée de l’Amicale DANZ Antilles.

Le site est déployé sur GitHub Pages et utilise Supabase pour l’authentification, les profils, les actualités, l’agenda, les documents et la galerie.

## Accès

L’accès au contenu est réservé aux comptes validés par un administrateur.

- Les amicalistes se connectent avec leur adresse e-mail validée et un lien de connexion sécurisé.
- Les administrateurs se connectent avec leur adresse e-mail et leur mot de passe.
- Les nouvelles demandes d’accès sont validées depuis l’espace d’administration du site.

## Déploiement

Le site est publié à l’adresse :

https://amicale-danz-antilles.github.io/danz/

L’insigne DANZ Antilles est utilisé comme icône officielle de l’application et est publié depuis le dossier `public/`.
